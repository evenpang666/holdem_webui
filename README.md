# 河牌 · 局域网德州扑克

## 一键启动

启动脚本会检查并安装 [uv](https://docs.astral.sh/uv/)，使用 Python 3.12 在项目目录创建 `.venv`，再根据 `uv.lock` 下载并安装锁定版本的依赖。首次启动需要网络连接；以后重复运行会复用已安装的环境。

**Linux：** 在项目目录运行 `./start.sh`。如果文件没有可执行权限，先运行 `chmod +x start.sh`，或者直接运行 `bash start.sh`。

**Windows：** 双击 `start.bat`，或在命令提示符中运行 `start.bat`。首次安装 uv 时需要可用的 PowerShell。

启动后会自动在房主的默认浏览器打开 `http://localhost:8765/`。按 `Ctrl+C` 停止服务。

若双击启动后仍看到旧页面，先关闭之前运行的游戏服务再重新启动；Windows 脚本会在 8765 端口已被占用时提示。页面与静态资源会获取最新版本。uv 的依赖缓存保存在项目的 `.uv-cache` 目录中；如果已有 `.venv` 无法读取，脚本会自动准备单独的备用环境。

依赖由 `pyproject.toml` 声明，并由跨平台的 `uv.lock` 固定版本。已有 uv 时，也可以手动运行 `uv sync --locked`，然后运行 `.venv/bin/python server.py`（Linux）或 `.venv\Scripts\python.exe server.py`（Windows）。

同一局域网的朋友打开 `http://房主IP:8765`，输入房间码加入。房主在牌桌右上角点击「邀请」可复制局域网邀请链接。如果连接失败，检查防火墙是否允许 TCP 8765。

## 玩法

- 固定小盲 ¥5、大盲 ¥10，无上限德州扑克；每次自愿下注或加注须为 ¥5 的倍数。
- 入座前设定 ¥5～¥1000 的带入筹码，不能在游戏中补码。破产后只能等待房主重新开始。
- 房主可随时添加电脑玩家，当前局进行中时下一局入座；最多 10 人。
- 房主可在牌桌下方用滑块调整电脑玩家的行动间隔，也可点击其他玩家座位上的「×」将其移出房间。
- 每次行动会在座位上方显示文字提示；摊牌后各玩家座位显示牌型，点击牌型可点亮其最佳五张牌。
- 左下角的实时聊天框可与同房间玩家交流；右下角的牌局日志按时间记录开局、下注、公共牌、牌型和结算，可随时展示或隐藏，默认展示。
- 玩家可点击右上角「退出房间」主动离开；房主离开时，房主身份会交给房间里的下一位真人玩家。
- 房主按「开始发牌」或「下一局」发牌；「重新开始」会踢出其他玩家并重置房主筹码。
- 刷新页面可凭本地保存的会话重连；加入过的 IP 地址会保存在浏览器中。

服务端统一洗牌、发牌、验证行动和分配主池及边池。断线玩家在轮到其行动时自动弃牌。游戏数据仅保存在服务端内存，服务进程退出后房间消失。筹码仅作游戏记分。
